## Installation

1. Download `mengclick-vX.Y.Z.zip` from the release assets.
2. Extract the archive.
3. Open `chrome://extensions` and enable **Developer mode**.
4. Select **Load unpacked**, then select the extracted folder containing `manifest.json`.

## Known limitations

- Chrome may throttle background timers; synthetic clicks may not work on every website.
- Element selection does not support iframes or shadow roots.
